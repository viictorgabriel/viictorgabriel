### 📊 Projeto de análise de dados

**[Análise comercial de soluções de IA e Segurança](https://github.com/viictorgabriel/revenue-sales-analysis)**

Estudo com dados fictícios para descobrir onde o valor das vendas se concentra, usando Python, SQL e Power BI. Principais achados:

- **44% dos clientes concentram 73% das vendas**: são os que têm oportunidades em IA e em Segurança.
- **IA (Copilot) responde por 77% das vendas**, com ticket médio 2,3 vezes o de Segurança.
- **Os cinco maiores clientes somam 59% das vendas**, o que pede acompanhamento dedicado.
